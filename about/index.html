so this is basically a page to help me remember and track my experience in setting up a new /homelab type server, and my experiments with os's and new computers/tablets. i started with NO server knowledge and many years (20+ now) using the linux desktop. this started long ago with a pentium 486 and ubuntu. progression was to mac for work friendliness and then back to linux fulltime after privacy concerns etc.

so now i type this on my main device a M$ surface pro9 with current kernel and patches using fedora rawhide as a base. i'll include as many details of my builds as possible and will start at the very beginning along with providing any hindsight and updates. maybe it will help others maybe it will just be a way for me to rebuild if something breaks.

current hardware:

  • system76 lemur (lemp13b) laptop w/ gentoo openRC btrfs snapper and grub-btrfs
  • M$ surface pro 9 (Intel) patched kernel for SAM implements, fedora rawhide
  • dell 730xd running proxmox 9.2 hosting vaultwarden, jellyfin, lxc and docker containers w/ GPU passthru
  • NitroKey i7-10710U Comet Lake w/ Alpine Linux openRC btrfs snapper and grub-btrfs and a few other experimental boxes...
